# EPL_Power_Rankings

A Premier League power ranking model built using Python and Pandas. 

# Project Overview

This project evaluates Premier League teams using:

- Goals Scored per Match
- Goals Conceded per Match
- Shot Creation
- Shot Prevention

These metrics are combined into a single Power Rating that ranks clubs based on overall team strength

# Data Source

football-data.co.uk

Historical seasons used:

-2024/2025
-2025/2026

# Methodology

## Offensive Metrics

-Attack Rating
-Shot Creation Rating

## Defensive Rating

-Defense Rating
-Shot Prevention Rating

## Power Rating

Power Rating combines:

-Offensive Strength
-Defensive Strength

to create an overall team ranking.
